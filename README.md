# Частный VPN для близких

Два самостоятельных узла в Европе, до 100 пользователей и трёх зарегистрированных устройств на человека. Основной режим — весь интернет-трафик через туннель. Согласованный предел регулярных расходов — €50/месяц; см. [бюджет](docs/budget-50-eur.md).

Репозиторий содержит рабочие административные инструменты, Ansible-конфигурацию и локальный сетевой стенд. **Работающего публичного сервиса пока нет: серверы не арендованы.** Не воспринимать подготовленный код как подтверждение скорости, доступности из РФ или прохождения испытаний на всех устройствах.

## Состав

- `vpnctl`: зашифрованный AES-GCM/Scrypt реестр, квоты, отдельные ключи каждого устройства и узла, выдача профилей, отзыв, резервная копия, настройка Telegram и email.
- Ansible для Ubuntu 24.04 x86_64: WireGuard, отдельный служебный туннель, nftables, частный DNS Unbound, обновления безопасности и аудит изменений.
- Полный набор peers применяется через `wg syncconf`: отзыв устройства не перезапускает туннель остальных пользователей. Более старая ревизия отклоняется.
- Grafana, Prometheus, Loki и Alloy: агрегированный трафик, ресурсы, ошибки, правила тревог, оба канала уведомлений. Панель слушает только localhost, удалённый сбор — через служебную сеть и mTLS.
- Защищённое администрирование ключом + TOTP. Изменения SSH и firewall имеют таймер отката и требуют проверки через новое соединение.
- Restic для зашифрованных внешних копий и сценарии восстановления.

## Проверка безопасности

Первоначальные находки в комплектных плагинах Grafana устранены заменой состава: официальный Grafana 13.3.0-slim и только два подписанных официальных плагина Loki/Prometheus 13.2.5 с закреплёнными SHA256. На 4 ноября 2026 проверка всех четырёх образов и обоих плагинов дала **0 HIGH/CRITICAL**, включая неисправленные находки. Допуск требует полного свежего отчёта по точному набору и закрывается при ошибке/находке; статус нельзя менять вручную. Это не сертификация безопасности. Подробности — в [отчёте проверки](docs/verification.md).

AmneziaWG предусмотрен как дополнительный backend, но требует проверенного пакета из официального репозитория, закреплённой версии и совместимых параметров клиентов. Его доступность/скорость не тестировались на VPS. В первоначальных примерах выбран стандартный WireGuard; перед покупкой длительных тарифов нужен пилот из российских сетей.

## Быстрая локальная проверка

Нужен Docker с Linux engine. Команды PowerShell из корня проекта:

```powershell
docker build -f tools/Dockerfile -t vpn-service-tools:local .
docker run --rm -v "${PWD}:/workspace" -w /workspace vpn-service-tools:local
docker run --rm -v "${PWD}:/workspace" -w /workspace vpn-service-tools:local python tools/validate_local.py
```

Проверка настоящего туннеля и firewall требует дополнительных прав **только одноразового контейнера**, интернета у стенда нет:

```powershell
docker run --rm --network none --cap-add NET_ADMIN --cap-add SYS_ADMIN --security-opt apparmor=unconfined --sysctl net.ipv4.ip_forward=1 --sysctl net.ipv6.conf.all.forwarding=0 -v "${PWD}:/workspace" -w /workspace vpn-service-tools:local python tests/network_lab.py
```

Тестовые ключи случайны и не предназначены для эксплуатации. Фикстуры находятся в исключённой из Git `.state/validation`. Они не являются inventory реальных серверов; не запускать по ним развёртывание.
