# Подключение пользователя

Администратор выдаёт два отдельных файла для каждого зарегистрированного устройства: основной узел A и резерв B. Файлы содержат приватные ключи: не пересылать их посторонним, не загружать в онлайн-генераторы QR и не использовать общий профиль всей семьёй.

1. Установить официальный клиент, совместимый с выданным протоколом: [WireGuard](https://www.wireguard.com/install/) для обычного WireGuard или официальный клиент AmneziaWG для согласованного AmneziaWG. Форматы похожи, но стандартный WireGuard не становится совместимым с AmneziaWG автоматически.
2. Импортировать оба файла, дать им понятные имена A и B. Подключать один профиль за раз.
3. Включить штатную защиту от обхода туннеля/kill switch, если она поддерживается выбранным клиентом. Системные настройки Android «Постоянная VPN» и «Блокировать соединения без VPN» проверить отдельно с конкретным приложением. На других ОС и телевизорах одинаковое поведение без испытаний не обещается.
4. Проверить внешний IP, DNS и IPv6 по инструкции администратора. IPv6 в текущей серверной конфигурации направляется в туннель и блокируется там: полноценный IPv6-интернет пока не предоставляется. IPv4 продолжает работать. Один профиль сам по себе не обеспечивает блокировку интернета после ручного выключения клиента — для этого нужна защита ОС/клиента/роутера.
5. Если A недоступен, отключить A, включить B. Из-за смены выходного IP звонок/загрузка могут переподключиться. Попробовать домашнюю и мобильную сеть; сообщить администратору идентификатор устройства, время, ОС, тип сети и симптом. Не отправлять ему содержимое приватного ключа в диагностике.

## Телевизоры

Android TV/Google TV/Fire TV: сначала проверить официальное приложение и совместимость версии. Для Samsung Tizen, LG webOS и неподдерживаемых моделей — отдельная Wi-Fi/проводная сеть за совместимым VPN-роутером или шлюзом. Для Apple TV нужен совместимый tvOS-клиент либо тот же роутер. Поддержка каждого телевизора напрямую не обещается.

Роутер получает собственный профиль и считается одним зарегистрированным VPN-устройством. Три профиля на пользователя не являются техническим способом подсчёта физических устройств за этим роутером. Производительность 4K зависит и от CPU роутера, и от Wi-Fi, и от канала провайдера.

## Российские сервисы

Начальная конфигурация пропускает весь трафик через VPN. Список прямых исключений — дополнительная настройка на совместимом клиенте/роутере, после проверки DNS, IPv6 и блокировки при обрыве. Не выключать весь VPN автоматически при открытии одного сайта: это затронет остальные приложения. Не импортировать случайные списки всех российских IP или всех доменов `.ru`.

## Если потеряли устройство

Немедленно попросить администратора отозвать его профиль. Старый файл после отзыва не использовать. На замену выдаётся отдельное новое устройство/ключ, остальные пользователи сохраняют доступ.

VPN защищает передачу до сервера. Он не делает интернет полностью анонимным, не заменяет HTTPS и обновления устройства и не гарантирует доступность каждого сайта или каждой сети.
